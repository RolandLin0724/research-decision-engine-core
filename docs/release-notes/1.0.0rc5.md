## Provenance remediation

This candidate removes private-source commit references from release-facing source,
documentation, runtime metadata, tests, wheel, and source distribution surfaces.
Exact private provenance remains only in external private evidence.

Three stable public role tokens identify the `SOURCE_DESIGN`, `PROTOCOL`, and
`EVIDENCE_CONTRACT` semantic roles. They are not Git objects, do not identify a
repository or ancestry, and are never used as Git revisions. Git reads use one
separately captured real implementation commit and record clean-worktree drift from
that commit.

## Compatibility

The public API remains exactly 112 symbols. SQLite remains schema v6. RunSpec,
RunBundle, and non-executing replay remain supported for v1, v2, and v3. Production
decision algorithms are unchanged. The sole public API semantic delta is
`research_decision_engine.__version__.value`, from `1.0.0rc4` to `1.0.0rc5`.

## Verification boundary

The candidate is validated on CPython `>=3.12,<3.13` for Windows and Linux,
with locked dependencies, 575 Core tests, reproducible wheel and sdist builds, 112
public symbols, and zero replay workload executions. These checks are not a
production-readiness or scientific-validation claim.

## Remaining publication gates

The sanitized product repository is public. Public security configuration,
public Windows/Linux CI, a complete public-boundary privacy audit, a release tag,
GitHub Release, PyPI publication, and any announcement remain separate future gates.
