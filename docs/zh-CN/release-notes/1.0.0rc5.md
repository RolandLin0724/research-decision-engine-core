## 来源修复

此候选从面向发布的源码、文档、运行时 metadata、测试、wheel 与 source
distribution 表面移除了私有源提交引用。精确私有来源仅保留在外部私有证据中。

三个稳定的公开 role token 分别标识 `SOURCE_DESIGN`、`PROTOCOL` 与
`EVIDENCE_CONTRACT` 语义角色。它们不是 Git object，不标识仓库或 ancestry，
也绝不会作为 Git revision 使用。Git 读取仅使用单独捕获的真实实现提交，并记录
从该提交到干净 worktree 的 drift。

## 兼容性

公共 API 仍恰好为 112 个符号。SQLite 仍为 schema v6。RunSpec、RunBundle 与
不执行工作负载的 replay 继续支持 v1、v2 和 v3。生产决策算法未改变。唯一公共
API 语义变化是 `research_decision_engine.__version__.value` 从 `1.0.0rc4`
变为 `1.0.0rc5`。

## 验证边界

该候选面向 Windows 与 Linux 上的 CPython `>=3.12,<3.13`，验证锁定依赖、
575 项 Core 测试、可复现 wheel 与 sdist 构建、112 个公共符号以及零 replay
工作负载执行。这些检查不构成生产就绪或科学验证声明。

## 剩余发布门禁

净化的产品仓库已经公开。公开安全配置、公开 Windows/Linux CI、完整公开边界
隐私审计、发布标签、GitHub Release、PyPI 发布以及任何公告仍是独立的未来门禁。
